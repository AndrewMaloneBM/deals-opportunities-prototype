## Summary judgment on visual fidelity priority (deviation from the task's default priority order — flagged as a decision)

The task's default priority order lists screenshots (1) above front-apps (3). Given that all local screenshots are 18+ months old and front-apps has a **currently shipping** implementation of almost this exact feature (component names, status enum, copy strings), I recommend treating **front-apps live code as co-primary with the screenshots** for structural/naming decisions, while screenshots remain primary for overall Back Office branding/chrome (colors, header, logo treatment) that changes less often. This is called out as a decision for Andrew to confirm in the main plan.
